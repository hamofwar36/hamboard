햄보드의 데이터는 기본적으로 사용자의 기기에 저장됩니다. 햄보드는 별도의 자체 서버에 사용자의 문서나 백업 데이터를 수집하지 않습니다.

Google Drive 백업은 사용자가 직접 Google 계정을 연결한 경우에만 사용됩니다. 햄보드는 Google Drive의 앱 전용 저장 공간에 백업을 저장하고, 백업 목록을 확인하고, 사용자가 선택한 백업을 복원합니다. 사용자의 일반 Google Drive 파일에는 접근하지 않습니다.

Google 계정 연결과 백업 처리는 사용자의 기기에서 Google과 직접 통신하여 이루어집니다. 햄보드는 Google 계정 정보나 백업 데이터를 전혀 수집하지 않습니다.

Google API를 통한 데이터 처리는 Google API Services User Data Policy 를 따릅니다.
