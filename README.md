# 🐹 햄보드

**만화 · 글 원고 작업을 위한 창작 보조 데스크톱 앱**

[📦 최신 버전 다운 받기](https://github.com/hamofwar36/hamboard/releases/download/v1.0.2/hamboard_1.0.2_x64-setup.exe)

## 🎯 주요 기능

* **작품** — 플롯부터 세부 장면까지 계층형으로 정리
* **마인드맵** — 인물 관계, 사건 흐름, 세계관 등을 자유롭게 배치
* **노트** — 소설, 설정 자료, 조사 내용 등을 자유롭게 작성
* 캐릭터 / 이미지 레퍼런스 / 메모 관리
* [[내부 링크]] / 네트워크 — 햄보드 안의 여러 자료를 서로 연결
* 캘린더 / D-day / 타이머 / 작업 기록 등 다양한 작업 보조 기능

## 📝 작품

큰 줄거리 흐름을 **파트 → 블록 → 세부 블록**으로 나누어 관리할 수 있습니다.

단편과 장편을 지원하며, 장편은 여러 화를 만들어 각각 관리할 수 있습니다.

* **🧱 파트** — 도입 / 전개 / 절정 / 결말 등 큰 흐름 구성
* **🧩 일반 블록** — 사건과 장면을 계층형으로 세분화
* **🎬 스크립트 블록** — 지문, 대사, 배경, 연출, PAGE, CUT 등을 나누어 작성
* 자주 쓰는 파트 구조는 **템플릿**으로 저장 가능
* 대사에 등록된 캐릭터 연결 가능

## 🕸️ 마인드맵

등장인물 관계, 사건 흐름, 세계관, 복선 등을 자유롭게 배치할 수 있습니다.

노드 배치·크기·색상 변경, 그룹 생성, 연결선 및 관계명 지정, 이미지 배치를 지원합니다.

작품·화·파트·블록·노트·캐릭터·자료 등 햄보드 내부 항목을 가져와 서로 연결할 수도 있습니다.

## 📒 노트

소설뿐 아니라 설정 자료, 세계관, 조사 내용, 아이디어 등을 자유롭게 작성할 수 있습니다.

다양한 글 서식을 지원하며 **HTML / Markdown 내보내기**가 가능합니다.

### ✒️ 맞춤법 교정 도우미

외부 맞춤법 교정기를 사용한 뒤 수정된 텍스트를 넣으면, 기존의 **굵게·기울기·밑줄 등의 서식은 유지**하면서 교정된 내용만 반영할 수 있습니다.

## 📎 자료 관리

### 🖼️ 이미지 레퍼런스 / 메모

작품과 함께 참고할 이미지와 설정·조사 자료를 관리할 수 있습니다.

이미지 레퍼런스는 자유롭게 크기를 조절하고 배치하는 보드 형식입니다.

### 👤 캐릭터 관리

작품별 등장인물을 등록하고 이름, 이미지, 색상, 별칭과 원하는 추가 설정을 관리할 수 있습니다.

## 👜 각종 유틸리티

* **📅 캘린더** — 반복 일정, 여러 날 일정, 작품 연결, D-day 연계
* **🗃️ 캐릭터 저장소** — 여러 작품에서 공통으로 사용하는 캐릭터 관리
* **🔗 햄보드 내부 링크** — `[[`를 입력하여 다른 문서와 항목 연결
* **🌐 네트워크** — 링크, 태그, 등장 캐릭터 등을 기준으로 자료 간 관계 확인
* **⚡ 퀵메모** — 햄보드 어디서나 우클릭으로 빠르게 메모
* **⏱️ 타이머** — 일반 / 반복 / 뽀모도로 타이머
* **🕒 작업 기록** — 등록한 프로그램의 작업 시간 측정 및 기록 확인, 작업시간 PIP 지원
* **🐹 펫** — 화면 위를 돌아다니거나 고정할 수 있는 데스크톱 펫
* **📖 사전** — 네이버 국어사전을 햄보드 안에서 사용
* **🏠 홈 화면** — 자주 사용하는 기능을 위젯으로 배치
* **버전 기록 / 완성·미완성 체크 / 태그 기능**

### 🏠 홈 화면 지원 위젯

📅 캘린더 · ⏱️ 타이머 · 🕒 작업 기록 · 📝 퀵메모 · 📆 D-day · 👤 캐릭터 저장소

필요한 기능만 골라 자신에게 맞는 작업 대시보드를 만들 수 있습니다.

## ⚙️ 설정

### 💾 데이터 관리

햄보드의 작업 데이터는 기본적으로 **사용자의 PC에 로컬 저장**됩니다.

설정의 데이터 관리에서 전체 데이터를 하나의 백업 파일로 내보내거나 불러올 수 있습니다.

추후 온라인 백업 기능을 지원할 예정입니다.

### 🎨 작업 환경

테마와 라이트·다크 모드를 지원합니다.

완성/미완성 표시나 태그 등 일부 기능을 취향에 맞게 켜고 끌 수도 있습니다.

### 🔄 자동 업데이트

새로운 햄보드 버전이 배포되면 앱 실행 시 업데이트를 확인합니다.
