개인정보처리방침

최종 수정일: 2026년 9월 23일

햄보드는 별도의 서버를 운영하지 않으며, 사용자의 개인정보나 작성한 데이터를 수집하지 않습니다. 모든 데이터는 사용자의 기기에 저장됩니다.

Google Drive 백업과 동기화

  • 사용자가 Google 계정을 직접 연결한 경우에만 사용됩니다.
  • Google Drive의 햄보드 전용 공간(drive.appdata)만 사용하며, 다른 Drive 파일에는 접근하지 않습니다.
  • 이 공간에는 백업과 기기 간 동기화를 위한 햄보드 데이터만 저장됩니다. 전송은 사용자의 기기와 Google 사이에서 직접 이루어집니다.
  • 설정에서 언제든 연결을 해제할 수 있고, 저장된 데이터는 앱의 백업 삭제 또는 Google Drive 설정의 앱 관리에서 지울 수 있습니다.

Google 사용자 데이터는 백업과 동기화에만 사용하며, 다른 목적으로 사용하거나 제3자에게 제공하지 않습니다. 햄보드의 Google API 사용은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요구사항을 따릅니다.

외부 서비스 접속

업데이트 확인, 공지, BGM 팩, 공휴일 표시, 사전 검색 기능은 GitHub, 네이버 사전 등 외부 서비스에 접속합니다. 이때 작성한 문서 내용은 전송되지 않으며, 사전 검색은 사용자가 선택한 단어만 전달됩니다.
