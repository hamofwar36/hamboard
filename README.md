# 🐹 햄보드

만화 · 글 원고 작업을 위한 창작 보조 데스크톱 앱

[📦 최신 버전 다운 받기](https://github.com/hamofwar36/hamboard/releases/download/v1.0.2/hamboard_1.0.2_x64-setup.exe)

## 🎯 주요 기능

* **작품** — 플롯부터 세부 장면까지 계층형으로 정리
* **마인드맵** — 인물 관계, 사건 흐름, 세계관 등을 자유롭게 배치
* **노트** — 소설, 설정, 조사 내용 등을 자유롭게 작성
* 캐릭터 / 이미지 레퍼런스 / 메모 관리
* `[[ ]]` 내부 링크 / 네트워크 기능
* 캘린더 / D-day / 타이머 / 작업 기록 등 유틸리티

## 📝 '작품' 문서 사용법

**🧱 파트** — 작품의 큰 흐름을 구성하고 템플릿으로 저장할 수 있습니다.<br>
**🧩 일반 블록** — 사건과 장면을 계층형으로 세분화해 정리합니다.<br>
**🎬 스크립트 블록** — 지문, 대사, 연출, 페이지, 컷 등을 나누어 작성합니다.

## 🕸️ '마인드맵' 문서 사용법

노드와 이미지를 자유롭게 배치하고 연결해 인물 관계, 사건 흐름, 세계관 등을 정리할 수 있습니다.<br>
햄보드 내부의 작품·블록·노트·캐릭터·자료 등도 가져와 연결할 수 있습니다.

## 📒 '노트' 문서 사용법

소설, 설정, 세계관, 조사 내용 등을 자유롭게 작성하고 HTML / Markdown으로 내보낼 수 있습니다.<br>
**✒️ 맞춤법 교정 도우미** — 기존 서식을 유지하면서 교정된 텍스트만 반영합니다.

## 📎 문서 내 레퍼런스 관리 기능

**🖼️ 이미지 레퍼런스 / 메모** — 참고 이미지와 설정·조사 자료를 작품과 함께 관리합니다.<br>
**👤 캐릭터 관리** — 이름, 이미지, 색상, 별칭, 추가 설정 등을 관리합니다.

## 👜 각종 유틸리티

**📅 캘린더** — 일정, 반복 일정, D-day, 작품 연결 기능<br>
**🗃️ 캐릭터 저장소** — 여러 작품에서 공통으로 사용하는 캐릭터 관리<br>
**🔗 햄보드 내부 링크** — `[[`를 입력해 다른 문서와 항목 연결<br>
**🌐 네트워크** — 링크, 태그, 캐릭터 등을 기준으로 자료 간 관계 확인<br>
**⚡ 퀵메모** — 어디서나 우클릭으로 빠르게 메모<br>
**⏱️ 타이머** — 일반 / 반복 / 뽀모도로 타이머<br>
**🕒 작업 기록** — 등록한 프로그램의 작업 시간 측정 및 PIP 지원<br>
**🐹 펫** — 화면 위를 돌아다니거나 고정할 수 있는 데스크톱 펫<br>
**📖 사전** — 네이버 국어사전을 햄보드 안에서 사용<br>
**🏠 홈 화면** — 자주 쓰는 기능을 위젯으로 배치<br>
**그 외** — 버전 기록 / 완성·미완성 체크 / 태그 기능

## ⚙️ 설정

**💾 데이터 관리** — 로컬 저장 및 전체 데이터 백업/불러오기 지원<br>
**🎨 작업 환경** — 테마, 라이트·다크 모드 및 일부 기능 표시 설정<br>
**🔄 자동 업데이트** — 앱 실행 시 새로운 버전을 확인합니다.
