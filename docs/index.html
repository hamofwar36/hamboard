주요 기능

작품

플롯부터 세부 장면까지 파트와 블록을 이용해 계층형으로 정리합니다.

마인드맵

인물 관계, 사건 흐름, 세계관과 이미지를 자유롭게 배치하고 연결합니다.

노트

소설이나 설정, 각종 줄글을 작성합니다.

참고 자료 · 캐릭터

이미지와 메모, 캐릭터 프로필과 이미지를 작품과 함께 관리합니다.

내부 링크

[[ ]] 내부 링크와 태그 등을 이용해 자료끼리 연결하고 바로 열어볼 수 있습니다.

작업 도구

캘린더, 타이머, 스톱워치, 뽀모도로, 작업 기록과 퀵메모 등 각종 작업 도구들도 사용할 수 있습니다.

문서 사용

작품

파트로 큰 흐름을 나누고, 일반 블록으로 사건과 장면을 계층형으로 정리할 수 있습니다. 스크립트 블록에서는 지문, 대사, 연출, 페이지, 컷을 구분해 작성합니다.

마인드맵

노드와 이미지를 자유롭게 배치하고 연결하며 브레인 스토밍을 할 수 있습니다. 또는 레퍼런스 보드로서 사용할 수도 있습니다.

노트

자유롭게 글을 작성하고 HTML / Markdown으로 내보낼 수 있습니다. 기본적인 줄글 작성 기능과 함께 각종 서식, 맞춤법 교정 도우미, 글자 수 세기 등이 가능합니다.

그 밖의 기능

  • 캘린더 — 일정, 반복 일정, D-day, 작품 연결, 일정 미리 알림
  • 캐릭터 저장소 — 여러 작품에서 공통으로 쓰는 캐릭터 관리
  • 참고 자료 — 이미지와 메모를 카드 형태로 관리하고 작업 중 따로 띄워 보기
  • 퀵메모 — 어디서나 빠르게 메모하고 고정
  • 타이머 — 일반 / 반복 타이머, 스톱워치, 뽀모도로
  • 작업 기록 — 등록한 프로그램의 작업 시간 측정 및 PIP
  • 펫 — 화면 위를 돌아다니거나 고정할 수 있는 데스크톱 펫
  • 사전 — 문서에서 단어를 선택한 뒤 우클릭해 바로 검색
  • 홈 — 자주 쓰는 문서와 유틸리티를 위젯으로 배치
  • 기타 — 태그 기능, 분할 화면 기능 등 다양한 편의 기능이 있습니다.
