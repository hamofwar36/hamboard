# 🐹 햄보드
만화 · 글 원고 작업을 위한 창작 보조 데스크톱 앱

[📦최신 버전 다운 받기](https://github.com/hamofwar36/hamboard/releases/download/v1.0.2/hamboard_1.0.2_x64-setup.exe)

## 🎯 주요 기능
**- 작품 (플롯 짜기, 상세 줄거리 관리)
- 마인드맵 (여러 요소들을 보드에 늘어놓고 브레인스토밍 하기)
- 노트 (줄글 쓰기)**
- 캐릭터 관리, 이미지 레퍼런스 관리, 메모 기능
- [[]]문법을 이용한 내부 링크 및 네트워크 기능
- 일정 관리, 디데이, 뽀모도로 타이머, 반복 타이머, 작업 기록(특정 프로그램을 실행한 시간 측정) 등 다양한 유틸리티 기능

## 📝 '작품' 문서 사용법
'작품'은 기, 승, 전, 결 등의 커다란 줄거리 흐름을 짜고, 다시 그 흐름을 세세한 블록으로 나누는 식으로 구성됩니다.
큰 플롯에서부터 상세한 장면, 한 컷, 한 문단까지 파고들어갈 수 있습니다.
작품의 형태에 따라 단편과 장편으로 나누어 관리할 수 있습니다.
장편의 경우 작품 안에 여러 화를 생성하고, 각 화마다 별도로 관리할 수 있습니다.
### 🧱 파트
예를 들면: 도입 → 전개 → 절정 → 결말 또는 1일차 → 2일차 → 마지막 날 처럼 자유롭게 사용할 수 있습니다.
자주 사용하는 구조는 템플릿으로 저장하여 다른 작품이나 화에서도 다시 사용할 수 있습니다.
### 🧩 일반 블록
줄거리와 아이디어를 정리하는 기본 블록입니다. 큰 사건 아래에 작은 장면을 계속 나누는 식으로 계층형 플롯 정리가 가능합니다.
### 🎬 스크립트 블록
만화의 글 콘티나, 대본 작업을 할 수 있는 블록입니다
지문, 대사, 배경, 연출, 페이지 구분, 컷 구분 등의 서식이 나뉘어져있어 편하게 입력이 가능합니다.
대사에는 미리 등록해둔 캐릭터를 연결할 수 있습니다.

## 🕸️ '마인드맵' 문서 사용법
등장인물 관계, 사건 흐름, 세계관, 복선 등을 자유롭게 배치해서 볼 수 있는 마인드맵입니다.
자유로운 노드 배치, 노드 크기 조절, 노드 색상 지정, 그룹 생성, 노드 간 연결, 연결선 이름 붙이기, 이미지 배치
예를 들면: A ─ 친구 → B, 사건 X ─ 원인 → 사건 Y, 7화의 복선 ─ 회수 → 8화의 사건
처럼 사용할 수 있습니다.
작품·화·파트·블록·노트·캐릭터·자료 등 햄보드 안의 여러 항목을 마인드맵에 가져와 연결할 수도 있습니다.

## 📒 '노트' 문서 사용법
자유로운 줄글을 작성할 수 있습니다.
기본적으로는 소설 작성용이지만, 설정 자료, 세계관, 조사 내용, 아이디어 등도 작성할 수 있습니다.
포스타입을 벤치마킹하여 다양한 서식을 만들어두었고, html이나 마크다운 양식으로 내보내기할 수 있습니다.
### ✒️맞춤법 교정 도우미
서식이 있는 글을 맞춤법 교정기에 돌렸을 때, 글의 서식이 초기화 되는 문제를 해결합니다.
글을 복사해서 부산대 교정기 같은 외부 맞춤법 교정 사이트에 돌린 후, 다시 돌아와서 '맞춤법 교정 도우미'에 복사해서 넣으면,
기존에 작성했던 굵게, 기울기, 밑줄 등등...은 그대로인채 변경된 맞춤법 텍스트만 자동으로 반영됩니다!

## 📎 문서 내 레퍼런스 관리 기능
### 🖼️ 이미지 레퍼런스 / 메모 관리
작품과 함께 참고할 이미지, 설정 자료, 조사 자료 등을 한곳에 모을 수 있습니다.
특히 이미지 레퍼런스 창은 자유롭게 크기를 조절하고 배치할 수 있는 보드 형식입니다.
※해당 기능은 PureRef를 참고하였습니다.
### 👤 캐릭터 관리
각 작품 안에 등장인물을 등록할 수 있습니다.
이름, 이미지, 캐릭터 색상, 별칭, 자유로운 추가 설정 항목 처럼 원하는 정보를 직접 추가할 수 있습니다.
별칭으로 등록한 문자열은 같은 캐릭터를 가리키는 이름으로 활용됩니다.

## 👜 각종 유틸리티
### 📅 캘린더
창작 일정과 마감을 달력에서 관리할 수 있습니다.
기본적인 캘린더 기능(반복 일정, 여러 날 일정)뿐만 아니라 작품을 직접 드래그해 넣어 일정을 연결할 수 있는 기능도 있습니다.
디데이 위젯과 연계가 가능합니다.
### 🗃️ 캐릭터 저장소
여러 작품에서 반복해서 사용하는 캐릭터나 세계관 공통 등장인물을 관리할 때 사용할 수 있습니다.
### 🔗 햄보드 내부 링크
글을 작성하다가 [[를 입력하여 햄보드 안의 다른 문서나 항목으로 연결되는 링크를 만들 수 있습니다.
관련 설정이나 장면이 여러 곳에 흩어져 있어도 링크를 타고 바로 이동할 수 있도록 만들었습니다.
### 🌐 네트워크
햄보드에 작성된 여러 정보를 바탕으로 작품과 항목 사이의 연결을 한눈에 볼 수 있는 네트워크 화면도 제공합니다.
직접 연결한 링크, 공통 태그, 등장 캐릭터 등을 기준으로 연결 관계를 확인할 수 있습니다.
자료가 많아졌을 때 “이 캐릭터가 어디에 등장했지?”, “이 태그와 연결된 장면이 뭐였지?” 같은 내용을 찾아보는 데 사용할 수 있습니다.
※해당 기능은 옵시디언의 그래프 뷰 기능을 참고하였습니다.
### ⚡ 퀵메모
갑자기 떠오른 아이디어를 바로 적기 위한 간단한 메모입니다.
햄보드 내 어디서나 우클릭을 누르면 바로 퀵메모 작성창이 뜹니다.
작업 중 이 대사 나중에 써야겠다 같은 생각이 들었을 때 바로 적어둘 수 있습니다.
### ⏱️ 타이머
작업할 때 사용할 수 있는 세 종류의 타이머가 있습니다.
일반 타이머, 반복 타이머(1시간마다 물마시기, 스트레칭 등), 뽀모도로 타이머
### 🕒 작업 기록
햄보드뿐 아니라 실제 작업에 사용하는 프로그램의 작업 시간을 기록할 수 있습니다.
등록한 프로그램을 기준으로 작업 시간을 측정하고 지정한 기간동안의 기록도 한 눈에 확인할 수 있습니다.
별도의 작업시간 PIP도 지원하여 작업하면서 현재 시간을 화면 위에 띄워둘 수 있습니다.
※해당 기능은 WORK WORK를 참고하였습니다.
### 🐹 펫
햄보드 안에 작은 이미지를 띄워둘 수 있는 데스크톱 펫 기능입니다.
이미지 하나만 넣으면 알아서 걸어다니며, 작업하다 보면 가끔 말을 걸어옵니다.
걸어다니지 않고 어딘가에 고정해두기도 가능합니다.
### 📖 사전
작업 중 단어나 표현을 바로 찾아볼 수 있도록 네이버 국어사전을 햄보드 안에서 열어볼 수 있습니다.
### 🏠 홈 화면
자주 확인하는 정보를 홈 화면 위젯으로 배치할 수 있습니다.
지원 위젯: 📅 캘린더 ⏱️ 타이머 🕒 작업 기록 📝 퀵메모 📆 D-day 👤 캐릭터 저장소
필요한 것만 골라 자신에게 맞는 작업 대시보드를 만들 수 있습니다.

## ⚙️ 설정
### 💾 데이터 관리
햄보드의 작업 데이터는 기본적으로 사용자의 PC에 로컬 저장됩니다.
설정의 데이터 관리에서 전체 데이터를 하나의 백업 파일로 내보낼 수 있습니다.
추후 온라인 백업 기능을 지원 예정입니다.
### 🎨 작업 환경
햄보드를 취향에 맞게 조정할 수 있습니다. 테마, 라이트 모드, 다크 모드를 지원합니다.
별로 마감에 쫓기고 싶지 않은 분들을 위해 완성/미완성 표시 제거 기능,
태그 기능을 쓰지 않는 분들을 위해 태그 표시 제거 기능 등 커스터마이징을 할 수 있습니다.
### 🔄 자동 업데이트
새로운 햄보드 버전이 배포되면 앱 실행 시 업데이트를 확인합니다.
